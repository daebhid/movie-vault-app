How to make a token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Expiration: No expiration (so you never sign in again)
  4. Repository access: Only select repositories → your data repo
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate, copy, paste it above
